## 产品介绍

围绕合租生活中费用分摊不清、清洁责任不明、
公共物品缺货和室友生活习惯差异等问题，
设计一个让账目透明、责任明确的合租生活管家。

## 核心功能

- **费用 AA 分摊**：新增账单、选择垫付人与参与室友，
  自动计算分摊金额，逐人记录结算状态。
- **清洁值日排班**：新增清洁任务、分配负责人、
  标记完成、调整排班，并支持下一轮值日轮换。
- **公共物品管理**：登记库存、记录消耗与补货，
  库存达到阈值时显示站内提醒。
- **室友公约管理**：新增和编辑公约、逐人确认；
  公约修改后重新征求确认。

## 建议体验顺序

1. 在「生活总览」查看共同支出、个人待支付及补货提醒。
2. 点击「记一笔」，体验自选参与人的 AA 分摊。
3. 在「清洁排班」中完成一项任务或安排下一轮值日。
4. 在「公共物品」中登记一次消耗或补货。
5. 在右上角切换室友，体验公约确认流程。
